# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux Toolkit.

## Features

- **Landing page** with the company name, a short introduction and a **Get Started** button.
- **Product listing page** with houseplants grouped into three categories (Air Purifying, Aromatic, Medicinal), six plants each, showing a thumbnail, name, description and price.
- **Add to Cart** buttons that add the plant to the cart, disable themselves once the plant is in the cart, and update the cart icon count.
- **Navbar** on the product and cart pages with links to Home, Plants and Cart, and a cart icon showing the total number of items.
- **Shopping cart page** showing each plant's thumbnail, name, unit price and subtotal, the cart total, buttons to increase / decrease quantity and delete items, a **Checkout** button (coming soon) and a **Continue Shopping** button.

## Run locally

```bash
npm install
npm run dev
```

## Tech

React 18, Redux Toolkit, React Redux, Vite.
